## 通用生成提示词

Use case: illustration-story. 项目游戏人物独立立绘素材。真实透明背景，单独一个人物，从头到小腿的四分之三身立绘，人物完整不切头不切手，双手解剖准确。站立，脸朝画面右侧约20度，身体朝观者，头顶留白约5%，人物占画布高90%。与中国山海叙事版画戏台保持统一：套色木刻版画＋精细钢笔线条，强烈形体轮廓，手工刀刻阴影，少量不规则纸上墨迹，成熟的文学插画，写实自然面孔，不是二次元大眼，不是3D。严格有限色：墨炭黑、暖骨白、铁锈朱红、黯金、灰青。平面大色块中有精确结构。无背景、无地板、无框、无文字、无水印、无光环、无星屑、不画环境。此为可叠放网页场景的透明人物切片，透明区不能画成棋盘格。
