## 提示词与制作规格整理

以下为本批素材的提示词规格整理，供继续生成时统一风格；不是对模型原始长提示词逐字转录。

1. **独立羽翼**：stylized-concept；游戏转场分层精灵，一对左右对称的象牙白、银白羽翼，羽片细密、轮廓利落，有自然层叠的长飞羽和柔软覆羽。两翼向外展开，翼根集中在画面中下方，正面平视、完整构图。真正透明背景，无人物、无躯干、无文字、无边框、无环境投影。优雅而有雕塑质感，适合在深蓝夜色背景上分离左右半翼并绕翼根旋转。
2. **天使身体**：stylized-concept；独立无翼的成年女性天使全身，银白象牙色兜帽长袍、精细褶皱与垂坠布料，双掌自然向两侧打开，正面居中，庄严安静，脚部和衣摆完整。保留清晰轮廓和细腻明暗，避免油亮塑料感。真正透明背景，无翅膀、无背景、无文字，适合置于三对独立羽翼前方。
3. **漂游幽影**：stylized-concept；孤立的幽灵精灵，侧向漂游的长发人形，淡银灰半透明轻纱、流动飘带与细长轮廓，姿态有方向感，适合暗红水下。完整构图、透明背景，无血腥、无湖泊场景、无文字，避免卡通笑脸和实体怪物的厚重质感。
4. **远处兜帽幽影**：stylized-concept；与长发幽影不同的孤立亡灵，背面偏三分之四角度，长兜帽与破碎柔软披纱、细腻灰白边缘、面目隐没，身体向上漂浮延展。透明背景，无地面与场景、无文字、无血腥，适合远景与低透明度叠层。
5. **雨窗景观**：stylized-concept；横幅夜间城市运河，从湿润窗户内侧望向外面，层叠尖顶屋舍、钟楼、远桥、冷灰蓝夜空和少量琥珀色窗光，细致雨水玻璃与水面倒影。高质量叙事游戏插画、空间深度清楚，整体克制，不能模糊一片；无人物、无文字、无界面装饰，供代码叠加动态雨滴、水痕和手部。
6. **血湖水面**：stylized-concept；横幅暗红与近黑色湖水纹理，细密起伏的低矮波浪、酒红反光与少量银灰碎光，有自然绘画质感和深度，覆盖整幅画面。无岸线、无天空、无人物幽灵、无文字、无图表线，适合在代码中缓慢移动并与透明幽影叠加。

金色锁链、齿轮、雨滴、水痕、辉光与折角为原生 SVG/CSS，保证链节清晰，连接点与对应齿轮同步移动。不是逐帧手绘视频，也不宣称完整骨骼、逐羽动画或真实流体模拟。

主流程在 `src/utils/menuTransition.js`；全局持久宿主在 `src/components/MenuTransition.vue`；分层组件为 SeraphEntrance、GoldenTether、HauntedLake、RainSceneLeaf；精修样式在 `src/menu-choreography.css`。素材预加载并等待解码，失败或超过等待期限时降级短渐变，后续操作可重试加载。简洁模式不挂载天使、血湖或雨景的大图层。
