# 前端衔接与切图修订

本轮以正常游玩和逐页衔接为目标，不调用付费故事生成。

- 时间：共用 storyTime.js 展示工具。优先使用已记录的故事时刻；与现场时钟相同则显示当前公开时刻，过去时刻显示相对时长；缺少日历依据时标为“启程后”，不把累计秒数编造成世界日期。不改变后台时钟或剧情结果。
- 人数：开局提示按剧情需要聚焦少量在场人物，不按美术库凑人数，无新增硬性人数拦截。同类型人物继续共用素材，角色身份与交谈目标仍按各自 ID。默认视觉示例仅两人，cast=gallery 才展示素材集合，cast=shared 专门检验共用精灵立绘。
- 切图：新图和专属背景解码完成后再切换；保留旧图并淡入淡出，取消左右裁切与 out-in 的空档。同图角色复用图片 DOM。快速切换与分支变化通过请求序号丢弃过期的加载结果，左右按钮不抢走键盘焦点。
- 衔接：右上小退出入口可进入主菜单或直接进入存档列表；不清除当前选择，不取消服务器正在处理的原操作。Home 根据 archives=1 自动打开列表。列表展示本局世界名，读取不调用世界生成。
- 视觉：重做贴边斜切导航旗、细线菱形轨道和淡景；共用罗盘、书页、蓝色墨迹与红色行动键，覆盖登录、注册、主菜单、存档列表和世界介绍/三问页面。手机保留小退出入口，外部页面正常滚动。
