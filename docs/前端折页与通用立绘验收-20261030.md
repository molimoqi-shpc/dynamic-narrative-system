## 立绘选择与失效处理

1. 仍优先使用已有立绘的具体人设、公开外貌和标签匹配。
2. 没有精确命中时，在兼容世界题材、性别及儿童边界的素材中，按最多公开特征选择近似图；不要求职业或关键词必须重叠。
3. 完全没有兼容素材、性别未知或题材尚未覆盖时，使用匿名通用留影。人物名称和资料照常显示，并标明“剪影”。这些画面是艺术示意，不回写人物服装、身份、物品或行为。
4. 原立绘加载失败，换为通用图片；通用图片也无法加载时，使用内置 SVG 作为最后的离线保护，避免右侧彻底留空，不循环重试图片。
5. 独行时显示“此刻独行”的旅人留影，不新增 NPC、不开放虚构的交谈对象。
6. 限知模式只使用公开外貌，不从名字、私人心理或隐藏档案反推性别和种族。图片选择不调用模型，亦不提交故事行动。

## 生图提示词原文

### COMMON-01

Use case: stylized-concept. Asset type: 正式叙事游戏中可直接使用的通用人物立绘，不是页面截图，不是排版，不是图标。请生成一张单人精美角色半身至膝部立绘，竖构图2:3，透明背景，完整保留头部与双肩、手臂、膝上衣摆，人物居中，边缘留少量透明余量。这是一位匿名旅者的文学式留影，性别不明确，成年但不强调具体年龄，体态自然、肩颈解剖正确，身材中等，不需要任何具体种族、职业和身份符号。人物身体朝向镜头，轻微向画面左侧转身，一只手自然搭住胸前翻起的衣料，另一只手在衣摆旁放松，姿态优雅、有静止中的张力，不抱武器，不托魔法球，不做手势。服装采用无时代标识的深灰蓝长外衣与自然搭在肩头的亚麻披布，领口和布料叠层干净考究，没有拉链、现代领带、军徽、盔甲、宗教符号、扣具和巨大配饰，能作为不同世界观中的匿名剪影使用。头部处在深而柔和的侧逆光阴影中，五官不辨，保留真实的头骨、下巴与侧脸轮廓，不要画空洞兜帽，不要画无脸机器人，不画骷髅，不画恐怖脸；几缕头发只以细腻边光出现，不强调长短与性别。整体质感达到高预算奇幻游戏封面立绘的半写实数字油画水平，有精密的笔触和克制的摄影级光感，衣料褶皱顺着肩、肘、腰部受力自然分布，亚麻细纤维、磨旧的边缘、缝线、厚薄不同的布层都可见，不能是简单几何块面，也不能是光滑矢量画。色调为石墨、雾银、灰蓝与极少量暖白边光，主体有明暗层次，肩头与衣褶上的细碎光泽形成高级、清晰的轮廓，面部和胸前不要被照成一张具体的漂亮脸。形体轮廓允许极细的干笔和发丝边缘，但没有漫天粒子、魔法光环、烟云、文字、字母、编号、水印、边框、地面、风景、建筑、道具或其他人物。画面外全部是真实透明alpha，绝不画棋盘格或伪透明灰底。需要作为放在精美实景背景前的主视觉立绘，即使是匿名角色，也要有服装层次、材料质感、精巧姿态与令人愿意多看的细节，绝不可做成粗糙的人形占位符。

### COMMON-02

Use case: stylized-concept. Asset type: 用于正式叙事游戏右侧人物舞台的精细通用立绘，单人透明PNG资产，竖构图2:3。请创作一位身份不明、性别不明确的成年旅者，整体为高级半写实数字油画、真实纺织质感与精密光影，绝不采用日系动漫、卡通、矢量插画、平面几何人形。人物从头至膝完整入画，站姿重心落在后腿，上身朝画面左侧，肩膀略向镜头转回，一只手自然下垂，另一只手在腰前虚拢住外衣，构成与正面站姿明显不同的回首侧身姿态。头部是一种真实但未被照亮的侧脸，暗部必须保留在深灰阴影里，不让读者认出具体五官与性别；保留人类头颈的真实比例，不画空兜帽、无脸假人、机械脸、骷髅和惊悚面具。头发只在背光边缘露出少量自然的碎发，绝不重点画女性的妆容、胡须或强烈性征。服装是一件没有时代符号的长外衣，肩头至腰部有自然垂落的多层软布，外衣轮廓简洁挺括，局部下摆被微风轻微掀动，袖口、肩缝、肘部、披布和腰侧应呈现极其精美而可信的褶皱与材质，不堆叠夸张装饰，不穿盔甲，不展示武器、法杖、书、翅膀、角、精灵耳或宗教首饰。画面用于身份资料未明的角色剪影，不宣称角色真有这些衣物，所以更强调人物形体、材料、背光和悬而未言的气质，不强调任何具体职业。色调以深石墨、雾蓝、暖灰亚麻与银白边光构成，明亮面只在肩头、手背、衣摆和少数褶痕，画出细密的布纤维、薄厚变化、细缝线、被光照透的薄布边缘，人物轮廓有自然发丝与干笔，像高预算游戏封面的精细原画。绝不生成任何背景，包括黑色渐变、灰色烟雾、背光圆盘、地面、环境、建筑、粒子、光环、投影底座或其他人物；人物以外的每一个像素都应透明，边光只落在人物本身，不外溢成背景。没有文字、编号、logo、边框或水印，不裁切头顶、手指或肩膀。最终应是一张可立刻叠在精美场景前的独立人物立绘，服装清晰、姿态自然、轮廓优美、细节耐看，达到成熟游戏角色资产的完成度。

### COMMON-03

Use case: stylized-concept. Asset type: 单独的游戏通用儿童人物立绘透明PNG，作为公开外貌资料不足时的文学剪影，不能和成人立绘混用。画面是一位大约八至十二岁、性别不明确的少年旅人，真实儿童的肩宽、身高、头身比与细小手掌，完全穿着厚实朴素的长外衣与短披布，穿平底布靴，衣服没有任何暴露或成人化设计。单人竖构图2:3，从头顶至脚完整入画，身体微微朝向画面右侧，头略抬起，好像望向远处，双手轻轻拢着衣摆，姿态安静而有生气，不持武器，不拿物品，不发光施法。人物不是任何知名角色，没有具体职业、民族、种族或宗教标识；服装只由无图案的深灰蓝织布、天然亚麻和简单缝线构成，没有铠甲、复杂首饰、拉链、帽檐标志、制服徽记、尖耳、翅膀或角。用成熟精美的半写实数字油画绘制，保持高预算奇幻游戏角色原画的完成度，衣褶和光影复杂但合理，儿童的身体比例必须准确，不能把成年人缩小，也不能让身体变成一个规则钟形。面部处在柔和而深的逆光暗部中，五官仅有模糊的真实轮廓，眼睛不清晰，不强调男孩或女孩的发型与脸部特征，不画化妆、胡须或成熟五官。头发在侧光下有少量自然发丝，肩头、手背、膝前与衣摆边缘有一线冷暖交错的细光，亚麻纤维、袖口卷边、缝线和布料的厚薄变化清楚可见。深石墨、灰蓝、雾白和暖灰为主色，拒绝大面积鲜艳配色，气质是安静、坚韧和未被定义的可能，绝不恐怖，绝不画黑洞一样的兜帽或无脸机器人。不要漫画线描，不要扁平矢量，不要玩具，不要低模，不要简单几何占位图。人物以外全部是真实透明alpha，没有黑底、灰底、白底、渐变背景、烟雾、场景、建筑、地面、底座、光晕、漂浮粒子、文字、标签、编号或水印；边缘发丝和衣料透明度自然，不允许整个角色被白色光圈包围。最终需要一张能直接放入正式游戏舞台的精美儿童剪影资产，和成人旅者素材保持相同的写实笔触、织物细节与光影精度。
