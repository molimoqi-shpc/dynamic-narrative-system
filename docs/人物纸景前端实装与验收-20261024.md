# 人物纸景前端实装与验收（2026-10-24）

本次实际修改正式项目 BS/frontend 和必要的公开外貌存档字段，不是仅交付概念图片。

## 已实现

- 内置 imagegen 独立生成 8 张透明立绘：少女两款、成年妇女、老年男性、神明、女孩，并补老年女性和成年男性。
- 另生成水岸、林间、云境 3 张环境图。所有 11 张图片已复制入 frontend/public/art/paper-theatre-v1，使用项目内固定路径，不依赖工具缓存目录。
- 正式 PlayView 使用左侧人物纸景＋右侧不透明书页，底部工具带提供人物、行囊、世界书、往事、六维、此间、音乐。旧常驻右栏内容移入可打开的此间面板。
- CharacterStage 以角色 ID 匹配公开外貌和稳定少女变体；世界书人物卡复用相同映射。切换图片、人物名和交谈对象同步；快速切换不会留下上一人物的图片。
- 外貌来源优先是玩家已有的 publicAppearance；旧档保守使用对应人物的公开介绍，不从姓名、私密心理或神职字段猜类型。信息不足时保留姓名意象牌。
- 主 API 的既有故事归档可选附 playerJournal.characterAppearances，保存 gender / ageGroup / divineRevealed / basis；服务端以玩家本人 role_knowledge 记录，场景与世界书读取同源资料。不新增独立模型请求，不用形象字段阻断故事，也不暴露尚未公开的神明身份。
- 纸边浮现 800ms，场景远景／人物／前景鼠标视差，场景淡交接，人物列表折页，章节入墨与重大决定展开；支持 prefers-reduced-motion。
- 保留原操作恢复、禁止重复发送、分支 revision、视角切换、存档回溯和终局阅读机制。修正归隐档被人物面板过滤的问题。
- 最新故事定位改为从最新篇章的开头阅读。手机以整页顺序滚动，正文与输入区不重叠。

## 明确边界

这是类型立绘库，同类型人物可能共用图片，并非所有人物各有独立肖像。旧存档缺少外貌事实时不批量编造年龄或性别；新故事正常归档外貌后自动配图。当前图片和 V5 保持布局、色调与版画方向，不能把静态概念图和动态程序宣称为逐像素完全一致。素材原始 PNG 总计约 31.3 MiB，网页仅按需要加载背景与所用角色。
