# 主页“继续游戏”齿轮转场

## 原因

`createMenuTransition` 曾用访问历史集合记录成功转场，并在第二次及之后打开存档时，自动设置 `reduced=true`。简洁转场样式会直接隐藏齿轮、锁链和背景机械装饰，因此用户选择完整动效时仍会突然失去齿轮。

原设计把减少重复等待的优化与用户选择的动效强度混为一体。动作时序和存档接口本身并不需要靠隐藏齿轮来保证可用。

## 修改

移除访问次数触发的自动降级；简洁转场只由主动选择的轻量/静态模式、系统减少动态效果设置或素材准备失败决定。保留跳过、导航超时保护、重复点击保护、遮罩释放及四种转场原时序。阅读设置中的说明同步更新。

此次没有修改后端、故事生成、存档数据、游戏布局、输入区或立绘。

## 检查

先修改回归用例复现问题：第二次打开存档预期完整动效，实际 `reduced=true`，用例失败。修复后相关6组37项测试通过，覆盖重复打开完整播放、揭幕结束前保留遮罩、跳过、静态设置中断、失败释放和存档请求生命周期。
