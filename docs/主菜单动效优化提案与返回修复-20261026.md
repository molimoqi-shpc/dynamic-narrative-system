## 返回与存档

- 开局页增加底部粘性返回栏：返回主菜单；三问阶段可返回世界介绍，不丢失本页填写内容，不重复请求世界。
- WORLD_PENDING 属于内部请求草稿，不写入前端所选存档标记，不列入存档列表。
- 主 API 成功生成并保存世界后才登记为可继续的存档。已有世界或已游玩内容不会因返回被删除。
- 从返回按钮离开时请求清理仍为空的草稿；与世界生成使用同一锁，避免删除已生成世界。
- 数据库仍会先建立内部草稿，用于请求恢复；直接关闭浏览器可能留下隐藏草稿，并非数据库完全不产生记录。退出请求为尽力清理，失败不妨碍返回；列表过滤持续有效。

## 下一版设计（待用户确认后实现）

统一逻辑：被点击菜单图形引出转场 → 主体动作形成遮挡 → 下一页在同一方向揭露。当前主要问题是中心道具独自播放，大片单色底缺乏空间关系，覆盖后又独立淡入下一页。下一版增加有来源的边缘装饰和景深，每种转场只保留两到三个辅助元素，避免堆满粒子、虚构符文与无意义文字。

### 新开一局：银翼与辉光

菜单上的羽翼纹样先轻亮，画面边缘出现低对比拱形线稿；中央天使的身体、左右翼与两层羽片依次展开，羽缘产生窄而清晰的逆光。光从翼间向外铺开，局部羽影先留住，再被辉光覆盖，最后从光中显露开局标题。不能用一张 PNG 宣称做到逐羽骨骼动画；需要可独立运动的翼层或羽片素材。主要动作约 1.8 秒。

### 继续游戏：合璧齿轮与档案门

两侧薄门板沿刻度轨道靠近，金色半齿轮啮合时有短暂停顿；内外环反向旋转，金属高光沿齿缘掠过，锁销对齐后中缝打开并露出存档页。背景使用暗纸、压印线和少量刻度，金色集中在机械部分。避免仅将两个圆盘推向中心再整体渐隐。主要动作约 1.7 秒。

### 引擎演示：黑红潮水

保留从下往上、越来越慢的运动。分成前景黑潮、中景深红反光、远景暗纹三个层次；液面窄红边缘随弧度起伏，局部形成少量缓慢墨涡，页面文字短暂透过液面后被吞没。覆盖完成后再展示新页，避免平整色块、明显波浪拼接线及重复淡入。主要动作约 2.1 秒。

### 关于本作：动漫少女手拉页与雨幕

保留细长动漫手。手指先在右下角接触纸边，页角从接触点卷起；折痕与投影随着手向下移动，旧页面被连续拉下，新页一直位于后方。雨分近远两层，前景少量长雨线，背景细雨更慢，折页边缘出现短暂水痕。手、纸角、阴影必须跟随同一个时间轴，不能手在拉、整页却只变透明。主要动作约 2 秒。

## 实现与验收约束

- 以 transform、opacity 和少量裁切遮罩实现。新增素材先预加载并 decode；不用大面积高频模糊。
- 继续使用当前统一转场状态机、重复点击锁、超时清理、Esc 跳过与减少动态效果选项。
- 页面进入动画与遮罩退场统一编排，避免两套淡入叠加。路由只触发一次，失败时释放遮罩和输入。
- 正常转场目标约 1.7～2.1 秒；网络请求耗时单独显示真实状态，不让动画冒充生成进度。
- 对每一种效果验收开始、中段、完全覆盖、揭露四阶段；另外检查窄屏、快速连点、Esc、素材失败及减少动态效果。以上新版动画尚未实现，不算本轮验收已通过。
