# 折光叙事全界面适配 · 2026-10-25

本次依据用户对正文、图文间距、留白与旧人物面板的反馈，统一前端视觉；不修改叙事、角色、时间、数值结算或存档逻辑。

## 本次修改

- 正文采用低对比度信纸横线。字号、行高和横线间距使用同一组 CSS 变量，段间距使用完整行距，手机与桌面分别适配。横线不盖住字。
- 桌面缩窄导航，收紧正文右侧留白，让人物舞台左移，减小原斜切边缘造成的空洞。人物轻摆、剪影、指针视差、入场和切换动画保留。
- 增加原创 SVG 线描飞鸟组件 FlightMark，用在章节页眉、人物卷宗、主菜单和账号页。不新增图片生成或故事模型调用。
- 新建 refraction-surfaces.css，将全局主题范围明确为 body.refraction-theme；覆盖旧纸景主题在传送到 body 的面板内部残留的黄纸、铜色、圆角和高优先级背景。
- 人物、六维、珍藏列表与详情、关系、世界书、剧情和伏笔、全知档案、公式、场景、说明、回溯、结局与存档窗口，以及音乐台均接入统一的纸灰、石墨、蓝色体系。
- 人物面板移除 profile-sheet 的 74vh 内层滚动上限，保留抽屉正文一个滚动区域；减少下方空白和嵌套滚动。
- 主菜单、登录注册、世界介绍和建角页同步适配，清理旧深色背景与新深色文字冲突、登录自动填充深色背景、建角玻璃卡片等残留。
- 开发预览增加 screen=home/login/creation，使用封闭适配器提供世界介绍和示例数据。珍藏、剧情、原章节和公式示例均标明为视觉示例，不用于真实结算或写入真实存档。
