# 薄输入区与分层转场实装 · 2026-10-26

## 修改

- 按用户第二张参考图缩减输入区：文本框及提交按钮从 66px 调整至 40px，改为单行初始高度；收紧标题、模式切换、辅助提示的上下间距。原有列宽、左侧导航和立绘布局未修改。文本框继续支持换行、滚动、手动纵向展开及 Ctrl/Command+Enter。
- 银翼：四层拱廊线稿、透视地面、两束光带、羽纹、翼片错时展开、羽缘亮层、中心向外的柔和辉光。仍复用现有天使图片裁切分层，不宣称拥有逐羽骨骼动画。
- 齿轮：压印门板、传动轨道、刻度、两只辅助齿轮、反向内环、中心锁销和窄高光；遮住画面后打开中缝及左右门板，实际存档抽屉在后方显露。
- 黑潮：远景六维图纹、三层液面、窄红光边、水下曲线、椭圆墨涡。调整上升曲线，保留末段减速；覆盖后向上退场显露引擎页。
- 少女手：复用动漫手素材，共用抓取坐标与移动曲线的纸叶/折角/手；背景采用主页已有车站图、雨窗线稿、两层雨线和涟漪。覆盖完成后切换至札记，再将整页向下拉走。移除旧主页自身拉动的第二套动画，避免动作叠加。
- 时长：银翼 1450+550ms；齿轮 1250+700ms；潮水 1650+500ms；少女手 850+1150ms，另有覆盖后 34ms 的绘制间隔。JS 与 CSS 共用时长，保留点击锁、Esc、跳过、失败清理与低动态模式。

## 验收

- 22 项前端定向测试通过：转场生命周期 10、阅读设置 7、导航 5。
- 四个入口在封闭本地视觉样例中实际点击，分别抵达开局、存档抽屉、引擎、札记。结束后检查无残留转场，根节点不再 inert。
- 桌面实测文本框高 40px；390px 窄屏实测文本框高 40px，文本框和按钮并排且未横向溢出。
- 逐一检查了真实 CSS 动画的中段定帧，以及手拉页退场露出目标页的定帧。定帧样例不冒充动画流畅度或帧率测量；未进行 FPS 性能基准测试。
- 本轮无真实故事模型调用、无生成新故事、无修改玩家真实存档。
