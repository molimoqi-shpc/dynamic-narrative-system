# 折光叙事与固定世界观 · 首阶段实施记录

日期：2026-10-25。以用户批准的《折光叙事预设计-v7》为视觉方向，已修改正式 Vue 页面及后端创建、上下文链路。本文记录实际实现与验收边界。

## 界面与动效

- 左侧窄导航、中间独立滚动的小说正文和稳定行动区、右侧人物舞台；瓷灰底、石墨文字、钴蓝断面、朱红行动按钮。
- 人物和姓名同一 keyed Transition，切换时以斜向遮罩退出/进入；初次入场同样有遮罩动画。
- 实像约 8 秒轻摆，幅度约 0.16 度、1–2 像素；独立单色影层约 9 秒漂移，避免两层一起平移像纸板。鼠标在舞台上改变微小视差与光的位置。
- 后台页面和不可见舞台暂停循环；系统减少动态效果设置会禁用动画与视差。
- 手机 390×844 布局已检查：人物区、正文、输入和底部导航均在屏幕内；旅程菜单提供存档、回溯与返回入口。
- 实测修复旧样式造成的横向正文挤压、手机输入移出屏幕、预览标记遮挡，以及焦点引起舞台内部滚动、人物头部被裁掉的问题。舞台使用 overflow:clip，正文独立滚动。

动效是透明 PNG 分层与 CSS 动画；不包含骨骼关节、眨眼或口型，不能称为 Live2D。概念图与实际页面并非逐像素一致，实际画面以本轮运行截图为准。

## 素材与匹配

新增西方六类：女性精灵、男性骑士、女性礼服贵族、女性战士、男性老年教宗、男性龙骑士。东方成年男女各一张重制图，另有西方背景意象。全部已放入 public/art/refraction-v1，人物均为 1024×1536 RGBA 透明图。

匹配使用公开外貌中的文化、性别、年龄组、种族、职业；不会从名字、心理或隐秘身份猜选。文化冲突、男童无对应图、女性骑士无素材、非人种族无对应图时显示未知形象。现代和科幻世界不会使用古典西方人物或大厅背景。

已逐个切换核对西方六类姓名、图片路径和图片加载；东方成年男女分别核对。东方少女、老人、儿童暂保留旧素材；现代/科幻与更多职业性别组合尚待扩充。类型素材可能供多个同类型 NPC 使用，尚不提供每人独一无二的脸。

## 世界生成和固定

1. /game/start 创建 WORLD_PENDING 存档，先不返回角色三问。
2. /game/world 使用主 API 生成世界标题、题材、时代文化、公开介绍、简略摘要、技术/能力边界和三个符合本世界的问题。
3. 世界以 session_world 独立保存。重复请求读取同一份世界；刷新恢复当前创建进度，失败保留存档供重试。不会生成假的替代世界。
4. 玩家先阅读世界介绍，点击“了解世界，建立角色”后进入三问、天赋、出生故事。
5. 天赋、出生故事、人物意愿、主故事、归档、结局及旧备用生成路径携带简略世界。正文可自然扩展细节，不重新随机时代或文化，也不把世界公共设定当作人物获知隐秘历史的依据。

新存档不默认主角是神明、神裔或有神职；界面改为身份、能力根基。旧档已经建立的神明身份继续保留。现有六维公式未被移除，文案通用化，不新增故事胜负校验。
