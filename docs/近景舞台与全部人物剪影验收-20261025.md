# 近景舞台与全部人物剪影验收

本次针对批准的 v7 预设计与实装差异，重做人物资产及合成构图。重点是近景镜头、侧身动作、独立偏移剪影、背景与人物之间的层次，以及正文的可读性。

## 已落地

- 六张新透明立绘：金发精灵、玫瑰红精灵、黑甲骑士、礼服贵族、教宗、龙骑士。用户认可的女战士文件保留，不重画。
- 用户明确认可的前两张精灵原图直接使用。所有完整提示词记录在《西方人物重制-v2-完整提示词-20261025.md》，每张 1157–1250 字符，均超过要求的 500 字。
- 骑士配套雪崖夜景独立保存并只绑定骑士，不修改游戏地点、时间与天气。
- 所有有可用立绘的角色使用同一套实像、独立偏移剪影、指针视差、入场和退出动画。夜景中的剪影采用较亮的冷蓝色，提高黑甲轮廓可读性。不是只给莉安写一个特例。
- 桌面舞台改为近景，人物和剪影越过场景图的斜切边缘；正文由独立纸层保护，保留信纸横线。行动区的白色斜切面延伸到人物前景，右侧姓名说明改为渐变明暗衬底。
- 修复旧伪元素的 340px 固定宽度、透明度及遮罩遗留，避免剪影压字；将主容器设为 overflow:clip，避免切人后的焦点自动滚动裁掉头部。正文仍在独立区域滚动。
- 新增 ROSE_ELF 公开外貌分类，性别、年龄、世界文化与种族不兼容时仍不套图；普通精灵继续使用原普通精灵类型。出生与故事归档提示词已包含该分类。

## 检查与边界

- 前端 113 项测试通过，其中新增红精灵与普通精灵区分、文化性别限制、骑士背景绑定测试。
- 后端本轮相关 35 项测试通过：人物日志 19、固定世界流程 5、创建流程 11。使用模拟模型，未调用付费故事 API。
- 前端构建与后端打包成功，最新版后端健康检查 UP。
- 浏览器逐个切换七类西方角色，确认实像与剪影路径对应、循环动画存在、主容器 scrollTop=0；已经修复了切换中实际出现的整页滚动问题。
- 这些立绘是类型代表素材，不能保证每个新 NPC 都拥有独一无二的脸；无匹配素材时继续使用未知形象，不从名字或心理猜性别。
- 目前采用静态 PNG 分层与 CSS 动效，不包含关节、眨眼和口型动画。实现目标是批准图的构图与层次，不以生成的概念图替代运行截图。

开发验收预览可加 ?focus=rose 或 ?focus=knight，直接将相应人物排在预览舞台首位。该参数只在封闭开发预览里处理，不进入正式游戏存档或模型提示词。
