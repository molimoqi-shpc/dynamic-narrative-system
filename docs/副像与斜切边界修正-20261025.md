# 副像与斜切边界修正

用户再次对照批准预设计后，确认上一轮实装仍有明显差距。本轮没有重画已认可的角色资产，也没有调用故事或图片模型。

## 根因与修改

- 原正文保护层使用整幅白色渐变，覆盖在副像上形成竖直的灰白雾带。改为不透明纸色与明确的多边形斜切边界，同时把保护层延伸至页眉，消除行首高度处的横向断层。
- 原副像经过 brightness(0) 处理，眼睛、鼻梁与衣料明暗全部丢失；参考图实际为可辨认面部的深蓝单色副像。现在用 SVG 双色映射保留亮度结构，夜景使用另一组冷蓝映射，原彩色人物素材保持不变。所有角色共用这一处理。
- 副像采用独立偏移、缩放与光影循环，彩色实像的默认镜头稍微缩小，保留持票手与上身动作。夜景、红精灵和原有角色匹配逻辑不改。
- 去掉桌面常驻的粗竖向滚动条，保留正文独立滚动。正文区域增加可聚焦的 region 与键盘操作支持；用 End/Home 实际检查滚动，主容器 scrollTop 仍为 0。
- 增大正文右侧安全间距，避免长文本滚到阅读区顶部时伸进斜切副像区域。

## 本轮验收

默认桌面窗口和 1680×945 宽屏均实际打开检查；切换骑士后配套夜景和冷蓝副像正常。生产构建成功。此次为局部视觉修复，没有把旧后端测试数当作本轮新测试结果，也没有执行收费故事实测。
