## 稳定性处理

- 保留全局转场宿主，页面切换发生在遮罩完全覆盖时，目标页面提交后再揭幕。
- 保留重复触发拦截、Esc / 按钮跳过、焦点与滚动释放、动作失败清理和页面响应超时保护。
- 按场景等待所需图片加载与解码；失败则使用简洁转场，失败缓存允许下次重试。
- 遵循完整 / 简洁 / 静态动效偏好，简洁模式不挂载新增天使、血湖和雨景大图层。
- 保留窄屏样式；本轮人工视觉验收使用实际浏览器默认 1280×720 视口，未将其他设备尺寸计入人工通过范围。
