# 前后端检查与武侠立绘接入 · 2026-10-27

本轮将E批07白衣女侠、08墨衣剑客接入正式游戏。新增批准图库累计40张，另有原有通用立绘。未新增角色、未更改故事的主创职责或语义判定，也未调用付费故事API。

## 已修复的问题

1. **东方新立绘不可达。** 原先东方角色直接返回旧立绘，不会进入批准图库匹配。现在先匹配适合东方世界的批准素材，没有合适素材时继续使用旧的通用形象；不再把缺少对应素材的已知非人类配成人类。两位剑客按性别、外表年龄、种族、职业、衣着与兵器选择。舞台、剪影、人物列表、世诰和天眼继续共用选图结果，新增图使用独立取景比例，不改侧栏或输入框布局。

2. **细化外貌在后端丢失。** 前端能按发型、眼睛、服装、持物、义肢和当前随行坐骑选图，后端此前只保存并返回少量基础字段。新增PublicAppearanceSchema统一整理可选公开外貌，贯通创建、故事归档、后续读取和部分更新。嵌套数据只保留公开展示字段，心理和秘密字段不会混入。公开外貌模板新增剑客、死灵、炼金、机械、海盗、血族等示例，仍按正文实际公开事实填写，不依素材库存造人。

3. **损坏的可选资料可能阻断后续保存。** 旧APPEARANCE或物品资料若为合法JSON数组等错误类型，直接强转ObjectNode会抛异常。现在对错误类型和空内容安全恢复，仅处理展示资料，不使其阻断已接受故事。

4. **旧登录与旧存档回包覆盖新状态。** 修复旧令牌迟到401清掉新令牌、旧/auth/me覆盖新账户，以及首页存档列表、读档和退出登录迟到后继续写状态的问题。游玩页面初始加载在离开页面或切档后停止后续读取；结局读取增加分支身份隔离，回溯后不再套用旧分支结局，读取失败保留现有存档展示并给出可恢复提示。

5. **4000字中文对白被16KB请求限制挡住。** 亲自交流会同时提交playerText和dialogue.spokenText，4000字中文的原始JSON约24KB，Unicode转义后约48KB。仅/api/game/operations与/api/game/action放宽至64KB，其他接口维持16KB；文字本身仍限4000字。增加原始中文、转义中文及超大请求的边界测试。

6. **模型密钥随源码配置进入构建包。** 将三个有效模型凭据迁入忽略目录下的.runtime/bs-local-secrets.yml，源配置和注释只保留环境变量引用；从BS或backend工作目录均能自动导入。原配置备份仅留在忽略目录。独立配置加载检查确认主、副与备用密钥能加载，新jar的application.yml不再含原明文模型密钥。未更换登录签名，也未轮换服务商密钥。更新了构建目录、依赖目录和本地缓存的忽略规则及运行文档。

7. **本地服务连接与运行状态。** 检查时8090没有监听，已构建并启动本轮后端。启动脚本将本地后端绑定127.0.0.1，Vite代理也明确使用同一IPv4地址，避免localhost解析差异导致连接失败。更新后端前只读检查运行操作，确认当前进程没有进行中的操作；历史中断记录保留，未删除或代为续接。
