# 导航联动、连续阅读与动效设置验收

日期：2026-10-26

本轮在现有视觉设计上完成三项前端优化，保留左栏偏角造型、Logo、输入框宽度及 40px 高度。没有修改故事生成规则，没有调用付费故事 API。

## 1. 导航反映实际面板

- 打开人物、行囊、世诰、往事、六维、场景时，左栏显示相应选中状态。
- 人物面板内部切换到行囊，左栏同步到行囊；关闭面板后恢复故事状态。
- 主要面板互斥，避免重叠遮挡。阅读与音乐浮窗也与主要面板协调关闭。
- 返回故事时保留阅读位置；已经处于故事页时可前往最近内容。
- 状态通过 aria-current、aria-pressed 和 aria-expanded 表达，供键盘及辅助技术识别。

## 2. 新内容到达与阅读位置

- 在真正应用接口结果前记录当前阅读位置，避免把请求等待期间的滚动覆盖掉。
- 阅读旧内容时保留当前章节锚点，显示“新内容已到”。点击前往第一段未读内容。
- 位于正文底部时，新章节从开头呈现，避免跳到长段落末尾。
- 重复轮询、状态或用量变化不重复提醒，也不重播文字入场。
- 章节正文补全、向前加载历史、多次批量更新、分支恢复与卸载都有独立处理。
- 新段落最多对九个标题或段落节点作短暂入场；正文始终可读，不使用逐字打字效果。
- 新段提示在正常布局内占位，不覆盖正文或输入框。

## 3. 三档动效

“此间”新增完整、轻量、静态三档，本地保存并跨标签页同步。

- 完整：保留页面入场、立绘视差与光影；同一页面反复打开存档时缩短齿轮仪式。
- 轻量：取消主要持续装饰与指针视差，以短淡入代替较大位移。
- 静态：停止动画与平滑滚动，仍正常执行跳转和释放操作锁。
- 系统要求减少动态时优先使用静态，不丢失用户保存的偏好。
- 存储不可用或内容损坏时有回退；切换档位会停止已经运行的相关效果。

设置浮窗改为内部正文滚动，标题及关闭按钮保持可见。检查时另外修复了辅助技术提示意外显示在画面上的问题。

## 验证结果

针对本轮与相邻功能运行 12 个测试文件，124 项全部通过，涵盖会话恢复、转场、导航、阅读、立绘与动效偏好。原有浅挂载测试仍会打印缺少 loading 指令的警告，未影响通过结果；干净浏览器验收页未记录 warn/error。

生产构建：Vite 5.4.21，1760 个模块，构建通过。

实际浏览器检查：

1. 桌面人物面板与行囊切换的左栏状态同步。
2. 完整、轻量、静态设置切换及刷新恢复。
3. 本地封闭样例延迟返回新章节：旧阅读位置保持，提示可点击且消失。
4. 390×844 小屏的新段提示不遮挡输入框，阅读设置的动效选项可达，关闭按钮始终可见。
5. 完整齿轮转场及重复打开存档结束正常；静态模式进入演示页后可继续操作。
6. 浏览器测量输入框高度为 40px；验收后恢复完整动效及默认视口。

真实浏览器故事测试使用 `theatre-review.html?readingDemo=1` 的显式本地夹具，仅检验真实 Vue 组件的交互与滚动，不创建真实存档，不联网生成故事。普通视觉预览继续拒绝未开放的写操作；本轮未将预览中的继续存档操作当作真实恢复通过的证据。

本轮结果不代表长篇故事生成质量或真实存档全流程已重新验收。
