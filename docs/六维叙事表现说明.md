# 六维叙事表现说明

更新日期：2026-10-20。

六维的说明同时进入角色意愿 API 与主故事 API。数值采用服务器已经计算好的实际值；主创临写资料再次列出各人的六维，以及已确立数值的最小值、最大值和差距，帮助主创把差异落实到故事中。

| 属性 | 较高时应体现的表现 | 较低时可以体现的差别 |
|---|---|---|
| 知 | 善用本人已有知识与经验，辨认事物，联系已知历史，给出有用解释 | 更多询问、查阅、对照或请熟悉者帮助 |
| 慧 | 发现因果和矛盾，比较多种解释，识别漏洞，想到有效办法 | 判断较直观，需要更多解释或证据，不强写愚蠢 |
| 斗 | 在交手、身体技艺、力量运用、反应和自保中体现熟练 | 动作较生疏、吃力，考虑工具与协作；实质交手按既有公式结算 |
| 闻 | 更加明察秋毫，更容易先察觉细微痕迹、声音、神情、环境异常与局势变化，并使发现帮助后续行动 | 尚未注意到某些细节，需要观察、提醒或询问后才能跟上 |
| 本 | 对本人已有神职、修行、力量运用和相关体验理解更深，体会已有经验中的要领 | 更依赖实践、请教和逐步体会；不因数值凭空获得法术、神格或突破 |
| 归 | 在恐惧、诱惑、挫折和利益冲突中更有定力，坚持自身已确立的信念、承诺与选择 | 更可能犹疑、动摇、权衡或寻求支持；不必然背叛 |

六项在相关情节中发挥作用，不要求每段硬塞六次展示。差距明显时，人物在同类事情上的表现也应有可读的差别，由主创结合实际处境创作，没有添加固定能力档位、成功率或普通剧情门槛。

知侧重知识储备，慧侧重解释和推理，闻侧重察觉，三者不互相替代。高知不凭空知道秘密，高慧不读心，高闻不远处全知。归指本人意志，不自动等于对玩家的忠诚。本的数值加成已经计入实际值，不重复乘算。所有表现仍结合人物实际所知、身体、经验与意愿。

主 API 的临写资料包括：

```json
{
  "characterUpdates": [
    {"roleId":"甲的编号","actualSixStats":{"zhi":8,"hui":8,"dou":12,"wen":8,"ben":0,"gui":15}},
    {"roleId":"乙的编号","actualSixStats":{"zhi":123,"hui":123,"dou":118,"wen":123,"ben":87,"gui":87}}
  ],
  "sixStatRanges": {
    "zhi":{"minActual":8,"maxActual":123,"gap":115},
    "hui":{"minActual":8,"maxActual":123,"gap":115},
    "dou":{"minActual":12,"maxActual":118,"gap":106},
    "wen":{"minActual":8,"maxActual":123,"gap":115},
    "ben":{"minActual":0,"maxActual":87,"gap":87},
    "gui":{"minActual":15,"maxActual":87,"gap":72}
  }
}
```

比较资料只交主创，不让角色 API 读取他人的属性或私有档案。未知能力不参与比较；只有一个已确立人物时不伪造对比对象。正常创作、内部续写与候选重写都经过同一入口。

本次更新复用原有模型请求，没有增加付费模型调用。针对性回归检查实际发送的主创消息、六项差距、未知占位排除、个人知识隔离与既有故事流程。此前交手实测见《六维实际游玩作用与实测》；本次新提示词对其他五维的真实叙事表现，仍需后续试玩审读，不能用消息组装测试代替文学效果。
