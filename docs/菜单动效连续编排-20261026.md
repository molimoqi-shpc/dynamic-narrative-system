## 点击到场景

点击后立即标记对应卡片，纹样亮起，其他卡片适当降低透明度；天使羽翼预展、齿轮与短链收紧、潮汐纹样上移，随后对应纹样从被点击卡片的位置移向中央，与全屏场景交叠显现。起点取实际卡片和纹样的视口坐标，兼容键盘触发与滚动后的位置。

220ms 的卡片反馈与图片准备并行；已有素材准备完成时只需等待这段短反馈，慢加载不会额外串行追加一次反馈等待。保留素材失败降级。简洁与静态模式使用短转场。

`menuEntry.js` 集中管理加载阶段的重复触发与清理：在图片加载期间退出主菜单，旧操作不会在加载完成后把用户带回原来点过的页面。全屏转场启动后，仍由原全局控制器负责跳转、遮罩和超时保护。

## 场景到页面

- 天使：辉光退去时，新局标题、步骤条、开局画面与世界选择内容按层显现。
- 齿轮：链轮向两侧退出后，存档标题、目录线与实际存档卡片从右侧轻移进入。等待存档列表请求完成并提交 DOM 后再揭幕。
- 血湖：潮面离场时，实际演示页标题与公式内容同步向上显现。
- 雨幕：整幅雨景被拉下时，下面的札记标题、鸟形纹样与正文条目分层出现。

原通用页面动画在菜单遮罩打开期间停用，避免它在遮罩下提前播放，也避免根页面与内部内容同时位移。目标页面仍只挂载一次，不靠动画事件触发业务或重复创建组件。

新增页面接应动画仅作用于指定目标，最多处理八个节点，全部在该场景的原揭幕时长内结束。动效偏好变化、页面隐藏、宿主离场时取消动画并清除标记；不支持动画 API 时直接显示正常内容。
