# 界面材质与图文融合优化

本轮按用户最新反馈修订：高级感来自自有的材质、构图、刻纹和侧光，不以紫色或铜色作为主题。参考大型角色扮演游戏对器物、受光边缘和卷宗信息层次的处理，保留本项目版画人物和小说书页的基底。

## 实际修改

- 正文 19px→16px，大屏 22px→17px；拆为真实段落，控制段距，文字仍可选择与阅读。
- 场景图通过同一个 --scene-art 延展到书页左侧，透明遮罩在文字下逐渐消失，原先硬切的整条白缝改成柔和的纸墨衔接。融合层不拦截点击，也不影响读写和滚动。
- 顶部、底部改用有明暗厚度的炭黑材质，去除大面积墨绿；自绘卷册、行囊、山形、六维印记等图标，菜单徽记有刻边、凹面与悬停侧光，鼠标移动时光线沿工具带移动，按下时下沉。
- 人物册使用较大的半身肖像与相逢录排版，去掉“成年女子／年轻女子”等分类标签的后台列表感。身份识别逻辑依旧来自已知资料和固定角色 ID。
- 成年女子改用新生成的 woman-v2.png（约30–34岁成熟面貌）；真正老人继续使用独立的 elder / elder-woman 素材。旧 woman.png 保留，不再作为普通成年女性的默认图。
- 天眼界面新增人物索引、卷首、角色肖像或姓名印记、档案戳记、六维小栏与文档层次，保留原来的意愿、独立记忆和裁决记录功能。加载失败时展示可重试的完整空状态。
- 用户截图中的“视角或存档正在同步”来自 theatre-review.html 未实现 /game/perspective 示例数据，本轮补齐该示例响应；正式接口的视角、分支和归属保护没有放宽。示例世界书也按限知／全知分别呈现已知资料或档案。
