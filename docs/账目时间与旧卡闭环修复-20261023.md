## 为何增加一次有条件的主 API 整理

实测证明，把全部存储栏目同时交给主 API，仍可能出现收付表列对而结论照抄旧卡的情况。因此，首次出现的重要账目或明确新证据，交给同一主 API 聚焦原章节、具体收付与相关公开卡，单独整理一次；成功结果缓存到 continuityState，稳定键相同且无新证据时跳过。仍由主 API 说明事实、人物说法和矛盾，没有程序按关键词判结案，也没有运行日常钱袋模拟。

本次聚焦调用分别实耗 ¥0.021615 和 ¥0.023732。若请求额度或网络使来源整理不可用，正文归档仍可保存，记录 UNREVIEWED；缺卡或缺累计摘要只标 PARTIAL，不冒充 DONE。不生成玩家待办或要求重演故事。已完整保存的归档在恢复时复用原响应，缓存完整性及不重复付费的分支均有免费回归。
