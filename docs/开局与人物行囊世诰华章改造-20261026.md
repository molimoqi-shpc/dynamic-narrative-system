# 开局、人物、行囊与世诰 · 华章改造

日期：2026-10-26。范围为用户指定的前端第 1、2 项；正文输入横条和游戏左栏几何保持原样。未调用故事 API，未在真实玩家存档中生成故事。

## 已实现

### 开局四步

- 世界介绍：独立卷首页，银纸羽翼插画、真实世界标题和简介、清晰主操作。
- 角色三问：左侧卷首边景、右侧分条问卷，保留回答长度、加载锁、已有回答恢复、返回介绍和空草稿处理。
- 天赋选择：三张契约卡，独立纹章、实际名称/描述/等级、鼠标和 Enter/Space 选择、明确选中反馈，保留原后端结算。
- 诞生：故事正文、地点、时刻、初见人物与进入游戏按钮。不再在界面强调内部坐标。

### 人物命谱与行囊

- 抽象纸鸟身份头图，不根据名字臆测玩家性别或套用 NPC 立绘；真实姓名、性格、地点和状态仍来自档案。
- 六维轮廓按当前六维相对绘制，真实数值单独列出，仍可点击查看公式；图形不宣称以 100 为属性上限。
- 伤势说明可展开，减少首屏占用；天赋、身世、身份根基保留。
- 行囊为重要物品列表与陈列详情，显示已知用途、故事牵系、来历、已知限制和借持归属；零件物品以真实空态展示，不填假装备槽。
- 关系分类与实际交往依据保留，空关系有独立空态。
- 当前存档的物品可以带名称跳转世诰；人物关系可带角色 ID 跳转。查看其他存档的命谱时不向当前游戏的世诰发起关联跳转。

### 世诰

- 前端展示文案由“世界书”统一改名“世诰”；原接口、数据库与内部组件名保持兼容。
- 分为天地卷首、人物与见闻、剧情与线索；目录、视角说明、人物卡、记录内页各有版式。
- 关键词、角色、世界时刻范围、分页和刷新功能保留。世界时间范围置于可展开的高级筛选。
- 人物卡可直接筛选相关见闻，本页见闻目录可定位至原文。
- 重要剧情保留编号、类别、已知线索与原章节关联；查阅章节时自动将原文滚入视野。
- 限知仍只展示已知内容；全知才展示幕后档案。原有同步清理、迟到响应隔离、分支/存档隔离未移除。

## 五张生图素材

位置：`frontend/public/art/illuminated-v1/`。

内置 image_gen 共生成五张：prologue-wing、shigao-frontispiece、relic-stage、talent-rosette、archive-raven。原始 PNG 保留；页面使用同尺寸 WebP（quality=90），五张合计约 1.8MB，减少约 87% 传输体积，未改画原始内容。

素材是装饰；所有名称、数值、正文、按钮仍为可访问的 HTML。立绘分配逻辑仍使用原来的文化/性别/年龄等资料。物品展台为空台，实际分类纹章由代码覆盖，不代表新增物品。

完整生成提示词：`frontend/public/art/illuminated-v1/prompts.json`。生成方式与素材用途：同目录 README.md。

- 没有进行跨所有浏览器的兼容性、FPS 基准或真实长期故事测试；本轮前端改造不冒充这些验收。
