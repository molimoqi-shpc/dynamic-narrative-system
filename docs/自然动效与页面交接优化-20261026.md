# 自然动效与页面交接优化

日期：2026-10-26

## 研究与取舍

本轮重新浏览与阅读了以下 5 个案例／规范：

1. [Persona 3 Reload](https://asia.sega.com/p3r/cn/)：查看去除宣传弹层后的主视觉，参考人物、背景与图形分层的动势；保留本项目既定斜切构图，不复制素材。
2. [Pentiment](https://pentiment.obsidian.net/)：阅读其艺术与动画说明及无障碍说明。借鉴画面内的有限运动，让纸页与人物保留原有画风，正文保持稳定。
3. [Carbon Motion](https://www.carbondesignsystem.com/building-blocks/foundations/motion/overview)：区分频繁操作的短反馈与重要场景的表现性动画；进入平滑减速，退出更短；关联元素编排顺序。
4. [web.dev 高性能动画](https://web.dev/articles/animations-guide)：优先 opacity 与 transform，避免逐帧布局以及不必要的 will-change。
5. [MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion)：尊重减少运动的系统偏好，提供静态内容，运行中取消非必要内容动画。

实际采用的速度是本项目的选择，并非声称这些网站都使用同一组参数。交互反馈约 120ms，内容约 300ms，弹窗约 320ms，角色约 460ms；四个主菜单仪式转场维持原有时长。

## 已实现

- 新增 `living-motion.css`，集中普通交互、浮窗、弹窗、抽屉、人物及四种主转场的节奏。
- 此间／留声改用完整 Vue 进入及退出过渡，收起时不再瞬间消失；退出层不拦截点击，音频仍独立存在。
- 抽屉外框先到位，卷首与存档卡片错开出现。子动画全部在父过渡结束前完成，避免父类移除后突然跳到终态。
- 终章、回溯、六维公式的卷首和正文错开进入，弹窗从较小位移平滑落定，退出缩短。
- `folioMotion` 指令用于路由页面、人物标签、物品详情、世诰分卷、公式标签等。新选择立即渲染；动画可取消，快速切换不会等待旧动画结束；不触发故事请求，不拦截输入，不持久写入 transform。
- 不同立绘使用统一淡入，字幕稍后进入。两位角色共用立绘时保留图片 DOM，仅轻柔更新字幕，谈话目标仍为真实选中角色。
- 剪影呼吸由 margin-left 改为独立位移，保留已有主体摆动及移位剪影。细线与轨迹跟随小幅鼠标视差，增加一层低强度反光；移动端及减少动态效果时不显示该反光。
- 天使拱线按远近错开，齿轮门上的刻纹先后响应，黑红潮水的六维文字依次浮现，雨中翻页的线稿渐现。四种主体、配图和目的页保持原设计。
- 46 条雨滴改为 transform 位移，替代逐帧 top 改变。
- 内容动画在系统减少运动或页面隐藏时停止；卸载移除监听器。CSS 同时覆盖新浮窗、弹窗、角色与抽屉的减少运动处理。

Logo、已认可的左侧斜栏、布局及细输入框没有重做。桌面复测输入框仍为 40px。

## 本轮实际发现并修复的问题

初版将生产入口的 `Transition mode="out-in" :css="!menuTransition.state.active"` 引入本地真实路由验收后，点击雨中翻页暴露了 Vue 页面同步卸载冲突，报 `parentNode` / `subTree` 空引用并留下遮罩。

现使用共享 `RouteScene.vue`：路由在遮罩下直接完成 DOM 交接，进入效果由可取消的内容动画负责，不再让 out-in 的同步卸载与路由 patch 竞争。主转场动作后额外等待 Vue nextTick，再开始揭幕。生产入口和示例入口使用同一组件，避免只验证示例特有逻辑。

新增真实内存路由回归用例，检查遮罩期间目标 DOM 已提交，开关遮罩不会重建旧页面或重复挂载新页面。
