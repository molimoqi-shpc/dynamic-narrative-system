# 刻线器物与辅助界面改造

日期：2026-10-26

## 实装范围

本轮继续适配主游戏之外的功能组件，保持既有 CompassMark 与 Logo、左侧斜栏和 40px 细输入区。

1. 登录及注册：折纸门扉、刻线内框、纸质表单、清晰焦点和反馈。
2. 旧梦存档库：时轴卷首、真实存档数量、卷号与状态、双列桌面和单列手机布局。
3. 此间：排字刻线、编号控制项、即时试读纸页；字号、字距、行距、段落留白、设备字体及恢复默认保留。
4. 留声：机械谐振卷首、刻线唱片、随真实进度变化的指针，保留播放、暂停、快进、音量、曲目切换。收起面板不停止播放。
5. 六维公式：独立六维标签、当前属性题签、公式稿纸和服务端数值明细。前端不重算实际数值。
6. 回溯：真实回合时间轴、地点名、玩家当时输入、刷新与原有回溯操作；没有可读地点时不暴露原始 sceneId。
7. 终章：书页化作纸鸟的卷首、原有总结分段、评价与后续操作；死亡和归隐使用不同标题，仍遵循原有终局状态。

界面装饰不增加剧情人物、物品或能力。Logo 未替换，也没有另做待替换版本。

## 操作问题修复

- 原登录按钮依赖 Vue 表单状态，浏览器自动填充而未触发 input 时会出现可见字段有值却无法提交。现在提交时读取原生 FormData，并先拦截正在进行的提交，避免 disabled 字段被读取为空。原有验证保留。
- 打开主要游戏弹窗时收起此间及留声浮窗，避免覆盖；音乐继续播放。
- 清除旧版唱片金色背景对新装饰的覆盖、回溯按钮颜色冲突和终章桌面全宽按钮继承。
- 手机回溯卷首缩减装饰尺寸，标题不再孤字换行。
