# 限知与天眼模式（2026-10-21）

两种模式读取同一段已保存正文，不调用模型重写故事。主角和NPC仍各自只依本人上下文行动；玩家通过天眼查阅的资料不会写入任何角色记忆。

| 功能 | 入梦 · 限知 | 天眼 · 全知 |
|---|---|---|
| 正文与玩家行动区 | 主角实际感知的正文、交流对象与场景记录 | 保持同一公开正文与行动区，避免把幕后人物自动变成主角已知对象 |
| 主角人物面板 | 自己的生命、六维、实际珍藏与已知关系 | 同样保留 |
| 世界书 | 交付给主角的故事、见闻和最近所见人物卡 | 增加角色私有附加表及已保存世界档案，可查询异地角色 |
| 天眼观察台 | 不出现入口，接口不返回私有载荷 | 顶部入口，分为真实资料、意愿与隐情、独立记忆、裁决记录 |
| 角色真实资料 | 不展示他人的真实属性、私有持物、隐秘态度 | 选择本存档角色，查看已确立六维及公式、当前保存生命与所在、实际持物及完整附加表 |
| 重要角色与龙套 | 只提供已知的有限资料 | CORE详细附加表、EXTRA现场简表、PLAYER标为主角；未确立数值不冒充实力 |
| 角色意愿 | 不展示未公开的内心、条件与打算 | 最近12段保留正文中实际采用的意愿；未提交片段和已被回溯删除的章节不展示 |
| 说谎 | 不显示后台标记 | 旧流程已明确记录的标记高亮；新流程可查表达/隐瞒意图，没有明确判断时显示“说谎状态未记录” |
| 记忆 | `/memory`为空，观察台接口无角色资料 | 所选角色独立记录按游标分页；另可查主角当前分层记忆 |
| 公式和裁决 | 不公开NPC的后台分数与原始快照 | 查六维公式、已保存回合快照及条件性交手参考；不把条件性胜负视为已经发生 |

## 切换与数据边界

- 顶部直接提供两种视角。服务端保存成功后才切换本地模式；保存失败保留原模式并明确提示，不假报成功。
- 切换期间暂停行动输入，关闭私有资料窗口，清空旧记忆/决策缓存；旧模式、旧存档和旧分支的迟到响应不能回填当前窗口。
- 世界书原有按关键词、角色、世界秒数范围与分页的查询继续按服务端模式筛选。天眼的角色选单可覆盖本存档角色；其他账号或其他存档角色不能访问。
- 角色附加表明确归档时刻，可能早于当前世界时刻。上方“当前生命/持物/实际所在”来自当前保存状态；下方心理与计划保留其历史含义，不捏造世界后台持续模拟。
- 交互场景统一使用主角已送达的观察，不再因缺少运行时记录而回退到NPC私有身体快照。

## 接口

- `GET /api/game/perspective?sessionId=...&roleId=...&beforeMemory=...`：所有权校验后读取视角；限知仅返回模式、版本与`available:false`，天眼返回选定角色资料、20条独立记录及更早游标、最近保留故事的意愿和裁决快照。
- `POST /api/game/view-mode`：只修改视角设置。不会推进时间、生成故事或更新角色知识。
- `GET /api/game/memory`及`GET /api/game/npc-decisions`：兼容入口也遵守模式；新故事意愿已接入旧决策追溯入口。
