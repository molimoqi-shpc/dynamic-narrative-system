# 世界书查询与角色卡

游戏页右上角“世界书”可打开查询面板。支持关键词、角色及世界故事秒数范围联合查询，每页 20 条；只读取存档，不触发角色 API 或主 API。

角色卡按当前存档更新。天眼展示当前场景人物，以及最新故事段落中确有附加表更新的其他人物，并分别标明来源。入梦展示此地最近实际所见的人物，不把旧观察当成实时追踪，也不会展示玩家未认识的人物目录。打开面板及故事版本变化时自动刷新。

## 卡片信息

- 天眼主要角色：可展开详细附加表，含身份、六维、处境、本人已知、过去经历、12 区心理及行动意愿。快照标明记录秒数，未更新的稳定信息承接旧档；意愿不等于已经发生的行为。
- 天眼普通龙套：只显示身份与职责、眼前关切、简单态度、愿提供的帮助、所知范围、边界，已有资料没有的栏目不补写。没有详细表时显示尚未记录。
- 入梦：不透露人物的幕后层次、精确六维、私有性格表、心理、隐秘动机、未公开关系、私人经历或行动计划。卡片只列最近所见时刻、可见身体状态及可见表现；性格从实际故事言行中了解。

限知隔离在后端执行，不将完整私有表传给浏览器再隐藏。天眼切换入梦时，前端同步清空旧数据并拒收旧请求；更换存档和回溯后的旧响应也不会覆盖当前面板。

## 查询范围及时间

入梦查玩家实际亲历的故事和已送达的亲见、听闻、转述、打听、调查、交往记录。即使某个世界事件标记为公开，只要玩家未获知，也不会直接收入限知查询。天眼额外可查世界书事件和角色档案，但不展示运行中的模型提案或原始操作载荷。

世界秒数来自故事存档，世界刻数另行保留，两者不混换，也不使用电脑时间代替。查询某一时刻时，覆盖该时刻的整段故事也会匹配。旧记录没有可确定的秒数时，在无时间筛选下保留原时标；填写秒数范围后不包含这些记录。支持角色精确关联及正文提及查询；关键词按字面匹配，百分号等字符不会变成数据库通配符。

接口：`GET /api/game/world-book/browse`。参数：`sessionId`、`keyword`、`roleId`、`fromSeconds`、`toSeconds`、从 0 起算的 `page`。认证及存档归属检查沿用游戏接口，视角以服务端存档为准。原 `/api/game/world-book` 地点接口保持兼容。

针对长存档，查询先排序小型索引字段，再读取本页正文；避免把长篇故事和详细附加表全部送入数据库排序缓冲区。功能不新增剧情资格判断，也不改动故事生成流程。
