# 战败处置、珍藏与人物牵系修改记录（2026-10-20）

原来的问题来自三个环节：故事模式仍沿用固定战败扣血；背包直接把日常用品当主要收藏并填空格；人际面板只看旧数值关系表，未归纳实际交往。

## 当前实现

- 角色附加表新增 combatDisposition：当前冲突性质、克制程度、获胜处置、落败应对、留情条件、救援意愿。仍使用原角色请求，不增加专用调用。
- 故事模式的公式提供胜负；主 API 结合角色意愿、经历和实际局势创作后续，实际伤势由 HEALTH 事件保存。切磋可无伤，真实敌对可死亡；不安排没有依据的救援。旧非故事协议仍保留旧行为。
- 主 API 在同次最终 JSON 中回写 playerJournal：真实姓名、重要物品资料、已知人际关系。面板读取不调用模型。物品资料不会授予物品，只附着于真实持有记录。
- 命谱改为真实姓名、六维、行囊珍藏、人物牵系。珍藏支持分类、搜索、排序，以及外观、已知用途、故事意义、限制、来历。普通生活用品不占主要珍藏，不绘制假空槽，不编造稀有度或装备加成。
- 人物牵系融合公开交往、亲历见闻、实际关系和盟约；明确的新关系优先于旧盟约记录。未认识人物不因处于同一世界就进入面板，限知模式不展示对方私密态度。
- 交战夺取物品新增 SEIZE，避免强夺被写成借用；此修正已做确定性回归。
- 首页与游戏页共用可读的独立命谱主题，修复首页打开时的背景与文字对比度。
