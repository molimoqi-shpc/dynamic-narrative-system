# 主创生成自动修复

**后续状态：已启用。** 2026-10-31 已核对源码快照和构建包并完成启动、登录及读档检查；之后又启用了原稿与不完整标记原子保存的修补。当前运行版本和验证结果见 [工程修补记录](工程修补记录-20261031.md)。下文的审批拦截是此前的历史状态，当前无需手动执行旧切换脚本。

本轮处理故事生成主链路：主创已经回复，但交接字段的格式缺漏使操作立即暂停，玩家必须手动续接才能继续。

## 修改及实际收益

- `ModelReplyFormatException` 明确表示“原回复已保存，仅协议字段未完成”，携带具体阶段；不靠错误文字判断是否应该重试。
- `CreationModelExchange` 在保存原稿与错误后使用该异常，保留现有调用方对 `LLMApiException` 的兼容。
- `ConversationOperationService` 仅对当前框架阶段的这种异常自动修复一次，沿原操作、原候选和原用量上限继续。成功的角色回复复用，不要求玩家为第一次结构缺漏手动点击续接。
- 正常有效回复不增加请求。超时、断网、限流和余额不足不进入该自动修复。持续错误最多自动修复一次后保留现场，不无限调用。
- 已完整生成的正文在结果字段修复期间保持原样，不重新生成正文或虚构行动效果。
